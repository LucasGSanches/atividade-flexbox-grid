# atividade-flexbox-grid
Atividade universitária da disciplina de desenvolvimento web sobre html e css

1. Alinhamento com Flexbox
A atividade foi feita com simples uso de flex e centralização dos itens no elemento.

2. Flexbox com Quebra de Linha
A atividade foi desenvolvida com uso de flex, tamanho dos elementos pré definidos com quebra de linha.

3. Layout Bidimensional com CSS Grid
A atividade foi desenvolvida com uso de grid, configurando colums com tamanho dinamico e rows pré definidos.

4. Grid com Áreas Nomeadas
A atividade foi desenvolvida com grid-template-areas, com rows pré definidos e colums de tamanho proporcional à tela.

5. Combinação de Grid e Flexbox
A atividade foi desenvolvida com combinação de grid e flex, grid sendo usado para controlar o conteúdo de todo site e o flex para um controle mais fino dos elementos.
